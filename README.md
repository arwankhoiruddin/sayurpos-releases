Berkas aplikasi dipasang di **GitHub Releases** (lihat menu Release di atas):

| Aplikasi | Cara pasang |
|---|---|
| **Kasir SayurPOS** (Android) | Unduh `kasir-sayurpos-*.apk`, buka di HP Android, lalu izinkan "pasang dari sumber tak dikenal" |
